# Terminologie-Mapping – SciBlog iWIP

Kontext: sprachliche Vereinheitlichung in Agentensteuerdateien

Status: historische Arbeitsnotiz des fruehen Terminologieabgleichs; keine
aktuelle Laufzeit-, Steuer- oder Terminologiequelle. Massgeblich sind die in
`AGENTS.md` genannten Cores und Prompts.

Dieses Mapping dient nur der internen Dokumentation.
Die technischen Begriffe werden in den Agententexten nicht parallel verwendet.

- Hardcheck -> Mindestpruefung
- Minimal-Check -> Kurzpruefung
- Gate -> Uebergang
- Scope -> Kontext
- Signal -> Statusmeldung
- Summary-Block -> Zusammenfassung
- Asset-Inventar -> Materialuebersicht
- Delta-Check -> Abgleich
- Guardrail -> Schutzregel
- Reporting -> Zusammenfassung
- Freeze -> Festschreibung
