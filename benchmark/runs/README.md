# Benchmark runs

Für jeden Lauf einen eigenen Ordner anlegen, zum Beispiel:

`B0-codex-current/`

Transkript, Laufmetadaten und Ergebnisartefakte gehören hierhin. Forschungs- oder
personenbezogene Daten werden nicht eingecheckt, bevor ihre vorgesehene lokale
Behandlung und Anonymisierung geklärt ist.
